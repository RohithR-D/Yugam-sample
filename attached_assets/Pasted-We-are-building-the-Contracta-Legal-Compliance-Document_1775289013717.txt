We are building the 'Contracta' (Legal, Compliance & Document Hub) module for our ERP. This handles active expiry-tracking for compliances, and includes a dynamic Letter/Document Builder for HR and Legal.

1. Navigation (Sidebar Structure):
Create a new top-level parent menu called 'Contracta'. It must contain EXACTLY these 5 sub-modules in this exact order:

Compliance Dashboard

Client Agreements

Vendor Contracts

Statutory Compliances

Letter & Doc Builder

2. Core Database Logic:

Compliances: Fields for Title, Category (Client, Vendor, Statutory), Valid_From, Expiry_Date, Status (Active, Expiring Soon, Expired), and Attachment. Auto-calculate status (Expiring Soon if < 30 days).

Templates: Fields for Template_Name, Category (HR, Legal, General), and Content_HTML (must support dynamic text placeholders).

3. Sub-module UI Requirements:

Compliance Dashboard: High-alert executive view. Top metrics: Total Active Contracts, Documents Expiring in 30 Days (highlight red/yellow), and Total Expired. Include an 'Upcoming Renewals' table.

Client Agreements & Vendor Contracts: Table views for contracts. Columns: Title, Entity Name, Valid From, Expiry Date, Status badge. Include an 'Upload Contract' modal requiring an Expiry Date.

Statutory Compliances: A critical table for government/factory licenses. Visually emphasize the Expiry Date.

Letter & Doc Builder: A robust template creation UI.

Left side: A list of saved templates (e.g., 'Onboarding Letter', 'Appraisal', 'Termination', 'NDA').

Main area: A Rich Text (WYSIWYG) Editor to draft the letter.

Crucial Feature: Include a 'Insert Variable' dropdown so users can inject placeholders like {{Employee_Name}}, {{Date}}, or {{Salary}} into the text.

Include a 'Generate & Print' button that opens a clean, margin-adjusted view of the document specifically designed to be printed directly onto pre-printed physical company letterheads (no UI headers/footers).

Please implement this exact architecture, paying special attention to the rich-text Letter Builder functionality!
