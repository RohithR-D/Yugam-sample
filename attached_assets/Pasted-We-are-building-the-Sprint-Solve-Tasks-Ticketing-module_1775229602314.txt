We are building the 'Sprint & Solve' (Tasks & Ticketing) module for our ERP. This module handles both proactive project tasks (Sprint) and reactive issue tracking (Solve). Use a clean, modern, data-dense design.

1. Navigation (Sidebar Structure):
Create a new top-level parent menu called 'Sprint & Solve'. It must contain EXACTLY these 5 sub-modules in this exact order:

My Workspace

Task Boards

Backlog & Planning

Issue Desk (Tickets)

Timesheets

2. Core Database Logic (Strict Adherence Required):

Tasks: Fields must include Task_Name, Parent_Project (Dropdown), Start_Date_Time, Due_Date_Time, Priority (Low, Medium, High), Status (New, In Progress, Review, Done), Description, Assigned_To, and support for Attachments and Reminders.

Tickets: Fields must include Ticket_Name, Type (Question, Bug, Maintenance, HR), Priority, Status (New, Open, Pending, Closed), Parent_Project, Due_Date_Time, Contact (Reporter), Description, Assigned_Team (Dropdown), Assigned_To (User Dropdown), and Attachments.

3. Sub-module UI Requirements:

My Workspace: A personalized dashboard for the logged-in user. Show two distinct lists/cards: 'My Active Tasks' and 'My Assigned Tickets'. Include a quick 'Start Timer' button next to active tasks.

Task Boards: A robust Kanban board UI for active Tasks. Columns should map to Task Status (New, In Progress, Review, Done). Cards must display Task Name, Priority badge, Due Date, and Assignee avatar. Include a 'Add Task' modal that incorporates all the fields defined in the Tasks database logic.

Backlog & Planning: A list view of unassigned or future tasks, allowing managers to sort by Priority and assign them to specific Sprints or Users.

Issue Desk (Tickets): A comprehensive helpdesk table UI. Columns: Ticket ID, Name, Type, Priority, Status, Assigned Team, and Due Date. Include an 'Add Ticket' modal that incorporates the exact two-tier assignment (Assigned Team -> Assigned To) and all fields defined in the Tickets database logic.

Timesheets: A ledger showing logged hours. Columns: User, Task/Ticket Reference, Date, Start Time, End Time, Total Hours.

Please implement this exact architecture, ensuring the 'Add Task' and 'Add Ticket' modals perfectly reflect the required data fields!
