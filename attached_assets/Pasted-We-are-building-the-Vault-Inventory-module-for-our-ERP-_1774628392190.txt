We are building the 'Vault' (Inventory) module for our ERP. This is an industrial-grade inventory system that handles raw consumables, finished retail products, and fixed assets. Do not hallucinate any other modules.

1. Navigation (Sidebar Structure):
Create a new top-level parent menu called 'Inventory'. It must contain EXACTLY these 7 sub-modules in this order:

Dashboard

Item & Product Master

Warehouses & Stores

Stock Movements

Material Issue

Store Management

Asset Management

2. Core Database Logic Requirements:

Catalog: Needs a type column (Raw Material vs Finished Product).

Locations: Needs a type column (Warehouse/Godown vs Store/POS).

Stock_Ledger: Must track Quantity per Item_ID per Location_ID.

3. Sub-module UI Requirements:

Dashboard: Show top metrics (Total Inventory Value, Total Items, Active Warehouses, Pending Indents). Include a 'Value by Category' pie chart and a 'Recent Stock Movements' feed.

Item & Product Master: A data table acting as the central catalog. Columns: Name, SKU, Category, Type (Raw/Finished), HSN/SAC, Unit Price, and Total Global Stock. Include an 'Add New' modal.

Warehouses & Stores: A table managing physical locations. Columns: Location Name, Type (Warehouse or Store), Capacity, Manager.

Stock Movements: A ledger view. Include a prominent 'Record Movement' button opening a modal. The modal must have a dropdown for Movement Type: Inward (GRN), Outward, Transfer, and Adjustment. Selecting 'Transfer' must show 'From Location' and 'To Location' dropdowns.

Material Issue: The industrial workflow UI. Split into two tabs: 'Pending Indents (Requisitions)' and 'Issued Logs'. The Issue modal must show the requested item, 'Requested Qty', an input for 'Approved Issue Qty', and a dropdown to select which Warehouse to deduct from.

Store Management: A clean retail/distribution interface specifically for locations marked as 'Stores'. Show available 'Finished Products' stock, and include a 'Create Sale/Issue' button to deduct finished goods.

Asset Management: A dedicated view for fixed assets (machinery/equipment). Columns: Asset Name, Serial Number, Status (Active, Allocated, Maintenance, Sold), Assigned To (Employee/Site), and Purchase Value. Include buttons to 'Allocate' or 'Log Maintenance'.

Please implement this exact 7-part architecture and ensure the UI looks modern and data-dense!
