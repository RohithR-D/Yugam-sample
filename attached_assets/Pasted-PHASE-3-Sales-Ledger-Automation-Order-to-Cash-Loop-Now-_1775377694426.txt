PHASE 3: Sales → Ledger Automation (Order to Cash Loop)

Now we connect the Sales module to the Ledger (Accounts) module. Every financial event in Sales must automatically create proper double-entry accounting records.

IMPORTANT: Every journal entry must balance — total debits MUST equal total credits. Never create a journal entry where they don't match.

Implement these 4 automated triggers:

TRIGGER 1: Sales Invoice Approved → Create AR + Journal Entry
When: sales_invoices.status changes to 'Approved' or 'Sent'
Do:
  a) Create a journal_entries record:
     - entryDate = invoice_date
     - reference = invoice_number
     - description = "Sales Invoice {invoice_number} - {client_name}"
     - status = 'Posted'
  b) Create journal_lines:
     - DEBIT: Accounts Receivable account (find in chart_of_accounts where accountType='Asset' and accountName LIKE '%Receivable%') for grand_total
     - CREDIT: Sales Revenue account (find in chart_of_accounts where accountType='Revenue') for taxable_amount
     - CREDIT: CGST Payable account for cgst_total (if > 0)
     - CREDIT: SGST Payable account for sgst_total (if > 0)
     - CREDIT: IGST Payable account for igst_total (if > 0)
  c) Create accounts_receivable record:
     - clientName = client_name
     - invoiceNumber = invoice_number
     - invoiceDate = invoice_date
     - dueDate = due_date
     - amount = grand_total
     - receivedAmount = 0
     - status = 'Unpaid'
     - entryType = 'Invoice'
  d) Update sales_invoices.journal_entry_id with the new journal entry ID
  e) Update chart_of_accounts.currentBalance for each affected account

TRIGGER 2: Sales Payment Received → Update AR + Journal Entry
When: A new record is inserted into sales_payments with status='Received'
Do:
  a) Create a journal_entries record:
     - DEBIT: Bank/Cash account for net_received amount
     - DEBIT: Bank Charges account for bank_charges (if > 0)
     - DEBIT: TDS Receivable account for tds_amount (if > 0)
     - CREDIT: Accounts Receivable for the full payment amount
  b) Update the linked accounts_receivable record:
     - Add payment amount to receivedAmount
     - If receivedAmount >= amount → status = 'Paid'
     - If receivedAmount > 0 but < amount → status = 'Partial'
  c) Update sales_invoices:
     - Add to amount_paid
     - Recalculate balance_due = grand_total - amount_paid
     - Update payment_status accordingly
  d) Update chart_of_accounts.currentBalance

TRIGGER 3: Sales Return/Credit Note Confirmed → Reverse AR + Journal Entry
When: sales_returns.status changes to 'Credit Issued'
Do:
  a) Create a journal_entries record:
     - DEBIT: Sales Revenue for taxable_amount (reversing revenue)
     - DEBIT: CGST/SGST/IGST Payable for tax amounts (reversing tax liability)
     - CREDIT: Accounts Receivable for grand_total (reducing what client owes)
  b) Create accounts_receivable record:
     - entryType = 'Credit Note'
     - amount = grand_total (as negative or use separate credit tracking)
  c) Update the original invoice's AR record — reduce the outstanding amount
  d) Update chart_of_accounts.currentBalance

TRIGGER 4: Invoice Overdue Check (Scheduled/Cron)
When: Run daily (or on every page load of AR dashboard)
Do:
  - Find all accounts_receivable where status IN ('Unpaid','Partial') AND dueDate < TODAY
  - Update status to 'Overdue'
  - Update corresponding sales_invoices.payment_status to 'Overdue'

SAFETY RULES:
- Wrap each trigger in a database transaction. If ANY step fails, rollback everything.
- Before creating journal entries, verify the required accounts exist in chart_of_accounts. If they don't exist, create them with sensible defaults:
  - "Accounts Receivable" (Asset)
  - "Sales Revenue" (Revenue)
  - "CGST Output" (Liability)
  - "SGST Output" (Liability)
  - "IGST Output" (Liability)
  - "Bank Account" (Asset)
  - "TDS Receivable" (Asset)
  - "Bank Charges" (Expense)
- Log every auto-generated journal entry with source = 'AUTO:SALES'
- Never create duplicate AR records — check if one already exists for this invoice before creating
